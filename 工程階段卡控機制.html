📌 工程生命週期系統 — 卡控機制極簡規格

Dev Cheat Sheet / 開發人員邏輯與關卡對照表

一、 跨模組解鎖門檻 (Workflow Gates)

[基本資料] + [預定期程] 皆完成存檔 → 解鎖 [預算額度] 與 [執行狀況]
[執行狀況] 輸入「實際開工日」 → 解鎖 [施工進度]
[執行狀況] 輸入「實際竣工日」 → 解鎖 [工程驗收結算保固] 與 [巡查登錄] (※ 巡查登錄維持原規則：依工程驗收判斷)
[執行狀況] 輸入「結算完成日期」 → 解鎖 [財產登錄] (※ 原判斷：竣工驗收後解鎖 ➔ 變更為：填寫結算完成日期後解鎖)

二、 基本資料 (Basic Info)

  • 填寫順序：計畫資料 → 工程資料 → (是否有分項工程 Checkbox) → 聯絡資料
  • 動態開關 (Checkbox Logic)：
    Unchecked 無分項：
    • 隱藏：分項工程欄位、按鈕、分項工程填報清單
    • 顯示/必填：主工程「工程內容 (選填)」、「工程位置 *」、「XY座標 *」
    • 清單卡控：[生態檢核自評表 *] 為必填（未填阻擋存檔）；[用地取得情形] 為選填
    Checked 有分項：
    • 展開：第 1 項分項工程欄位（編號 *、名稱 *、內容 (選填)、工程位置 * 全部強制必填）、[+新增分項] 按鈕、動態生成「分項工程填報清單」
    • 清單卡控：[生態檢核自評表 *] 為必填（未填阻擋存檔）；[用地取得情形] 為選填
  • 防呆機制：取消勾選 Checkbox 時，跳出二次確認視窗，確定後清空分項欄位資料。

三、 預定期程 (Schedule Control)

  • 時間軸順序：
    測設預定完成日期 ≤ 預定決標日期 ≤ 預定開工日期 ≤ 預定竣工日期
  • 日期卡控邏輯：
    • 關鍵規則：每個日期的「後者日期不可小於前者日期」（但可以等於同日）。
    • 防呆處理：若「後者日期 < 前者日期」，顯示警告訊息並阻擋儲存。

四、 執行狀況 (Execution Status)

  • 階段順序與解鎖門檻：
    • 規劃設計階段：填寫「測設完成日期」 → 解鎖 [招標階段]
    • 招標階段：填寫「契約編號 *」、「訂約日期 *」 → 解鎖 [施工階段]
    • 施工階段：填寫「實際開工日 *」解鎖 [施工進度] 模組；填寫「實際竣工日 *」 → 解鎖 [驗收付款階段] 模組及 [巡查登錄] 模組
    • 驗收付款階段：填寫「結算完成日期」 → 解鎖 [財產登錄] 模組
  • 時間軸順序 (後者 ≥ 前者)：
    用地取得日期 ≤ 辦理說明會日期 ≤ 測設完成日期 ≤ 上網公告日期 ≤ 決標日期 ≤ 訂約日期 ≤ 實際開工日期 ≤ 實際竣工日期 ≤ 驗收日期 ≤ 結算完成日期

五、 預算額度 (Budget Control)

  • [工程設計]：填寫工程費、空污費、其他、技術服務費。
    ↳ 解鎖條件：[執行狀況] 輸入「測設完成日期」
  • [工程發包]：填寫工程費、空污費、其他、技術服務費。
    ↳ 解鎖條件：[執行狀況] 輸入「決標日期」
  • [經費變更與實付款]：填寫變更追加減、契約總價、實付款紀錄。
    ↳ 解鎖條件：[工程發包] 解鎖時同步連動解鎖
  • [工程結算]：填寫工程費、空污費、其他、技術服務費。
    ↳ 解鎖條件：[執行狀況] 輸入「結算完成日期」
